# たしざんランド

子ども向けの足し算学習Webアプリです。スマホ・iPad・PCのブラウザで動きます。

## 入っているモード
- みてたし算：キャラクターを数えて足し算
- すうじでたし算：数字だけの問題
- 10をつくろう：10になる組み合わせ
- おはなし算数：短い文章問題
- タイムアタック：60秒で何問解けるか
- おまかせ練習：年齢に合わせて問題タイプを自動選択

## 年齢設定
3〜9歳を選択できます。年齢に応じて数字の範囲が変わります。

## 使い方
1. `index.html` をブラウザで開きます。
2. 年齢を選びます。
3. 好きなモードを選びます。

## ファイル
- `index.html` 画面構成
- `styles.css` デザイン
- `app.js` 問題生成・採点・記録

## メモ
キャラクターは既存作品をそのまま使わず、オリジナルの緑色マスコット風デザインにしています。
進捗の「スター」「連続正解」はブラウザの localStorage に保存されます。
